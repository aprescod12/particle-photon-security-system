## Project Context

This project was developed in Spring 2024 as a final embedded systems course project.
At the time, development was done entirely in Particle’s Web IDE (`build.particle.io`),
and the code was not version-controlled on GitHub.

In 2026, the project was added to GitHub to:
- Preserve the work in a permanent repository
- Improve documentation and readability
- Include the project as part of a professional engineering portfolio

No functional changes were made to the original system logic.
